# Тестовые сценарии для процесса "Как поступить в Школу 21"

## SC-001: Проверка отображения страницы поступления
**Предусловия**: Пользователь открыл главную страницу сайта.

**Шаги**:
1. Перейти в раздел "Поступление" через главное меню
2. Проверить заголовок страницы: "Как поступить в Школу 21"

**Ожидаемый результат**:
- Страница загружается без ошибок
- Заголовок отображается корректно

## SC-002: Проверка этапов поступления
**Предусловия**: Пользователь на странице поступления.

**Шаги**:
1. Прокрутить до блока "Этапы поступления"
2. Проверить количество этапов (должно быть 4)
3. Кликнуть на каждый этап для раскрытия описания

**Ожидаемый результат**:
- Все 4 этапа отображаются
- Описание раскрывается при клике

## SC-003: Проверка формы подачи заявки
**Предусловия**: Пользователь на странице поступления.

**Шаги**:
1. Нажать кнопку "Подать заявку"
2. Заполнить обязательные поля:
   - Имя
   - Email
   - Номер телефона
3. Отправить форму

**Ожидаемый результат**:
- Форма отправляется успешно
- Появляется сообщение "Ваша заявка принята!"

## SC-004: Проверка валидации формы
**Предусловия**: Пользователь открыл форму подачи заявки.

**Шаги**:
1. Оставить поле "Email" пустым
2. Ввести невалидный номер телефона (например, "123")
3. Попытаться отправить форму

**Ожидаемый результат**:
- Форма не отправляется
- Появляются сообщения об ошибках

## SC-005: Проверка ссылок в разделе "FAQ"
**Предусловия**: Пользователь на странице поступления.

**Шаги**:
1. Прокрутить до блока "Частые вопросы"
2. Кликнуть на каждый вопрос
3. Проверить работоспособность ссылок

**Ожидаемый результат**:
- Ответы раскрываются при клике
- Все ссылки работают (статус 200)

## SC-006: Проверка адаптивности страницы
**Предусловия**: Пользователь открыл страницу на десктопе.

**Шаги**:
1. Изменить размер окна на мобильный (375px)
2. Проверить:
   - Отображение меню
   - Переносы текста
   - Работоспособность кнопок

**Ожидаемый результат**:
- Контент отображается корректно
- Все элементы доступны

## SC-007: Проверка контактных данных
**Предусловия**: Пользователь на странице поступления.

**Шаги**:
1. Найти раздел "Контакты"
2. Проверить:
   - Email: admission@21-school.ru
   - Телефон: +7 (XXX) XXX-XX-XX

**Ожидаемый результат**:
- Контакты соответствуют официальным данным
- Клик по email открывает почтовый клиент
