# План тестирования раздела "Корпоративное обучение" (Школа 21)

### 1. Объект тестирования
**Тестируемый раздел**: [Групповые интенсивы для руководителей и команд](https://21-school.ru/corporate-training/gruppovye-intensivy-dlia-rukovoditelei-i-komand)  
**Целевая аудитория**: HR-специалисты, руководители компаний  
**Основные функции**:
- Подача заявки на обучение
- Просмотр программ и условий
- Контакт с менеджером

### 2. Виды тестирования

#### 2.1. Функциональное тестирование
- Проверка работы форм:
  - Отправка заявки (валидные/невалидные данные)
  - Проверка кнопки "Связаться с менеджером"
- Проверка контента:
  - Корректность отображения текста
  - Работоспособность ссылок

#### 2.2. UI/UX тестирование
- Адаптивность (мобильные/планшеты/десктоп)
- Соответствие дизайн-макетам
- Удобство навигации

#### 2.3. API тестирование
- Проверка отправки данных форм
- Валидация ответов сервера

#### 2.4. Кросс-браузерное тестирование
- Chrome, Firefox, Safari, Edge

#### 2.5. Нагрузочное тестирование (опционально)
- Проверка стабильности при высокой нагрузке

### 3. Чек-лист ключевых проверок

| № | Область проверки | Метод проверки | Ожидаемый результат |
|---|------------------|----------------|---------------------|
| 1 | Доступность страницы | Запрос страницы | Статус 200 OK |
| 2 | Отправка валидной формы | Заполнение всех обязательных полей | Успешная отправка |
| 3 | Валидация полей формы | Ввод некорректных данных | Сообщения об ошибках |
| 4 | Работа кнопки "Связаться" | Клик по кнопке | Открытие формы/переход |
| 5 | Отображение карточек программ | Визуальная проверка | Корректное отображение |
| 6 | Проверка контента | Ручная проверка | Отсутствие ошибок |

### 4. Инструменты тестирования
- **UI тестирование**: Selenium, Cypress
- **API тестирование**: Postman
- **Нагрузочное тестирование**: JMeter
- **Кросс-браузерное тестирование**: BrowserStack

### 5. Критерии приемки
- Все ключевые функции работают согласно требованиям
- Отсутствуют критические дефекты
- UI соответствует макетам

### 6. Отчетность
- Баг-репорты в Jira
- Итоговый отчет с метриками:
  - Количество выполненных тестов
  - Процент успешных тестов
  - Список найденных дефектов
