# Тест-кейс: Успешная авторизация на сайте Saucedemo  

**ID:** 001  
**Приоритет:** High (Критичный)  
**Тип теста:** Positive  

### Предусловия  
1. Пользователь находится на странице авторизации: [https://www.saucedemo.com/](https://www.saucedemo.com/)  
2. У пользователя есть валидные учетные данные  

### Шаги выполнения  
1. В поле **Username** ввести `standard_user`.  
2. В поле **Password** ввести `secret_sauce`.  
3. Нажать кнопку **Login**.  

### Ожидаемый результат  
- Происходит переадресация на страницу каталога (`/inventory.html`).  
- Отображается заголовок страницы **Products**.  
- В левом верхнем углу видно меню-бургер (☰).  
- В правом верхнем углу отображается иконка корзины.  

### Постусловия (опционально)  
- Выйти из системы (если требуется очистка состояния).  

### Дополнительная информация  
**Тестовые данные:**  
- Логин: `standard_user`  
- Пароль: `secret_sauce`  

**Примечания:**  
- Проверять в браузере Chrome версии 120+.  
- При ошибке "User is locked" использовать другой аккаунт.  

**Статус:** ✅ Passed (или ❌ Failed)
